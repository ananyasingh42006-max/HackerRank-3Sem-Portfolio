# Time Conversion

## Problem
Convert a 12-hour AM/PM time format into 24-hour format.

## Approach
- Read the hour, minute, second, and AM/PM value.
- Convert 12 AM to 00 hours.
- Convert PM hours by adding 12, except for 12 PM.
- Print the time in 24-hour format.

## Complexity
- Time Complexity: O(1)
- Space Complexity: O(1)
