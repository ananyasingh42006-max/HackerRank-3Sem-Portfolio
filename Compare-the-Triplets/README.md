# Compare the Triplets

## Problem
Compare the scores of Alice and Bob in three categories and calculate their points.

## Approach
- Read Alice's three scores.
- Read Bob's three scores.
- Compare each corresponding score.
- Give one point to the person with the higher score.
- Print Alice's and Bob's total points.

## Complexity
- Time Complexity: O(1)
- Space Complexity: O(1)
